# 令和版ソーセージキャッチャー

スマホ縦画面向けのスライド操作3Dブラウザゲームです。ビルドツールやインストールは不要で、通常のHTML/CSS/Vanilla JavaScriptからThree.jsとRapier 3D compatを固定バージョンで読み込みます。

## 起動方法

このフォルダでローカルHTTPサーバーを起動します。

```bash
python3 -m http.server 8080
```

ブラウザで <http://localhost:8080> を開いてください。スマホから同じLAN内のPCへ接続する場合は、PCのIPアドレスを使って `http://PCのIPアドレス:8080` を開きます。

> CDNからThree.jsとRapierを読み込むため、初回起動時はインターネット接続が必要です。`file://` で直接開かず、必ずHTTPサーバーを使ってください。

## 遊び方

- タッチ操作では画面を左右へスライドし、マウス操作ではクリックせずカーソルを動かして、巨大な1本串の串先を指（カーソル）の真下へ追従させます。タワーが傾いていても、根元が傾きの分だけ自動でずれて串先が常に指の位置に来ます（根元は画面外へ出ることがあります）。上から物理演算で落ちてくるソーセージの下へ串を合わせます。
- 串先とソーセージ本体のコライダーが実際に接触したときだけ `PERFECT` / `GOOD` になります。上方向へ突き上げる操作はありません。
- 中央付近なら `PERFECT` で100点、端なら `GOOD` で50点です。端刺しはタワーの重心を偏らせ、反対側を狙うとバランスを戻せます。
- 刺したソーセージはRapierが返した実際の接触点で串に接続され、地球重力に近い `9.81 m/s²` で串軸を自由落下します。各段の停止位置は固定間隔や疑似摩擦モーターで指定せず、有効なままのソーセージ同士のコライダーが衝突して決めます。古い段も固定ジョイントには切り替えず、全段がプリズマティックジョイントのまま常に下向きの重力を受け続けます。
- 刺したソーセージはジョイント方向へ小さく滑り、互いに押し合います。10本からフォークとタワー全体が震え、20本から長い金属部の曲がりと揺れが強くなります。
- 串先は物理的に連続した一本の直線軸として伸びます。長さは本数の固定倍率ではなく、現在刺さっているソーセージのうち最も高い上端（斜め・縦向きは傾きから算出）と先端余白から毎フレーム算出します。ソーセージが重力で下がれば串も縮み、積み上がれば伸びます。
- すべての投球は画面上部から始まり、串が移動できる左右範囲内（タワーが傾いているときは、その傾きで串先が届く範囲）の落下地点を通るよう、重力を含めて初速を逆算します。プレイヤーは落下地点を読んで串を横移動させます。
- 1本の串先はゲーム中ずっと物理コライダーとして働き、Rapierの接触マニフォールドに含まれるワールド座標を刺し位置として採用します。広い近接判定や中心線への位置補正は使いません。その接触点を両剛体で共有するプリズマティックジョイントに使い、横ずれを拘束しながら串方向へ重力落下させます。Rapierのプリズマティックジョイントは両剛体の向きを揃えて固定するため、刺さった瞬間にソーセージ剛体の向きをフォークに合わせ、接触時の傾きはコライダーとメッシュ側のオフセットへ移します。これにより横向きへ矯正されず、横・斜め・縦の刺さった角度と偏りを保持します。刺さったソーセージと串先の接触はジョイント作成時に無効化し、ジョイントだけで保持します。物理演算は画面のリフレッシュレートに依存しないよう1/60秒の固定ステップで進めます。
- ソーセージの姿勢は水平に限定せず、斜めから縦まで変化します。約30%は76〜90度の明確な縦向きで落下します。刺さり判定に角度制限はなく、水平なら側面、縦なら端面中央からでも、実接触点と重心を通る串軸が近ければ保持されます。接触点が重心線から離れすぎた場合はジョイントを作らず、Rapier剛体のまま串に弾かれて落下します。
- 投球時に到達位置と到達角度を逆算しますが、刺した後の積み重なり方はRapierの重力、ジョイント、ソーセージ同士の接触に任せます。偏りによるバランス値も、作為的な加点ではなく各剛体の質量と重心位置から毎フレーム算出します。串からの横ずれはジョイントで固定されるため刺さった瞬間の値を使い、高さだけを物理演算から読みます（揺れによるジョイントの伸びを拾って串が振動しないようにするため）。
- 床と床用コライダーは使用せず、背景内でフォークとソーセージだけを表示します。
- 落ち方は通常・ゆっくり・急降下の3種類です（投球名の表示はしません）。どれも画面上部からフォーク先端へ向かって素直に下降し、カーブ・ナックル・横からの飛来は使いません。開始位置は先端の左右へ少しだけずらし、速度と重力、控えめな回転だけに差を付けます。カメラの表示範囲から開始位置と初速を毎回逆算するため、タワーが高くなって画面が縮小しても画面内に現れ、先端の到達位置を通過します。
- ソーセージの素材は `assets/` の normal・bacon・cheese・herb・spicy・white・charred・gold・rainbow（各 `.webp`）から選ばれ、起動時にそれぞれのノーマルマップとラフネスマップを生成するPBRマテリアルを適用します。gold は金属的な光沢、charred はつや消しの質感です。
- 形は ふつう・太い・細い・長い・曲がった の5種類です。基本は normal 素材のふつうの形で、20%の確率でレアとして別の素材・形（またはその両方）が出ます。レアの中でも gold と rainbow は特に出にくくしています。当たり判定も形に合わせ、まっすぐな形はカプセル、曲がった形は凸包コライダーを使います。太いソーセージほど重く、バランスへの影響も大きくなります。
- 刺さった瞬間の位置と回転はフォークのローカル座標へ変換して保持するため、接触した場所から別の位置へ移動しません。
- 端刺しの偏りは各ソーセージの質量と実際の重心位置からフォークの傾きへ反映されます。偏りは画面上のメーターでは表示せず、フォークの傾きだけで伝えます。フォークが約70度まで完全に倒れた時だけ固定が外れて崩壊します。同じ偏りでもタワーが高いほど大きく傾き、約8本以上では偏りが `BALANCE_LIMIT` に達すると倒れる角度になります（3本以上で判定）。串の伸長量と刺せる本数には固定上限を設けていません。
- カメラはフォーク、刺さった全ソーセージ、突き上げた先端の到達地点を毎フレーム計測し、高さだけでなく傾いたときの横幅も収まる距離まで自動的に引きます。ソーセージが小さくなりすぎないよう、カメラ距離が上限（`MAX_CAMERA_DISTANCE`）に達したらそれ以上は引かず、串先と次の落下地点がある上側に合わせて映し、下側は画面外に切ります。
- 串の木製ハンドルは本来の長さを保ったままカメラの自動フィット対象から外し、画面下で自然に途切れさせています。スライド中は木製ハンドル、金属軸、刺さった全ソーセージが一体となって左右へ動きます。
- ソーセージが刺さって落ち着くたびに、串全体が収まる画像を裏で撮影します。リザルト画面にはタワーが一番長かったとき（最後に撮影したもの）の画像を、本数とスコア入りで表示し、Web Share API（非対応ならXの投稿画面）で画像と文章（本数・スコア・ハッシュタグ、公開中ならURL）をシェアできます。リザルト画面からは「リトライ」でもう一度、「タイトルへ」でタイトル画面に戻れます。ボタンは `assets/btn-*.webp` の画像です。
- リザルト画面にはベストスコアも表示します。更新したときは「NEW BEST!」とこれまでのベストを、更新しなかったときは現在のベストとあと何点で更新できたかを出します。
- ランキングは総合と今日（日本時間0時に切り替え）の2種類です。ゲームが終わると自動でランキングに記録され、順位が表示されます。同じ人（同じブラウザ）は1人1件で、ベストを超えたときだけ更新されます。名前は初回はサーバー設定の `default_name` で、リザルト画面で名前（10文字まで）を入れると、その人のランキングの表示名を登録・変更できます。タイトル画面・リザルト画面の「ランキング」から上位50件を見られます。`main.js` の `RANKING_API` が空のときは表示されません。
- 自己ベストはブラウザの `localStorage` に保存されます。保存できない環境でもゲームはそのまま遊べます。
- PCではドラッグのほか、左右の矢印キーでも操作できます。
- ソーセージがまだ飛来していない待ち時間や、画面内で0.35秒以上確認できなかった投球では失敗になりません。十分に表示されたソーセージを見逃した場合、または接触しても重心線から外れて `SLIP` した場合は、そのソーセージを物理落下させたうえで即ゲーム終了になります。

## 構成

- `index.html` — UI、import map、CDN読み込み、OGP（`assets/ogp.jpg`、1200×630）
- `styles.css` — 縦画面向けレイアウト、立体UI、タイトル／ゲーム背景の切り替え
- `assets/title-bbq-background.webp` / `assets/game-bbq-background.webp` — 画像生成した文字なしのBBQ背景
- `assets/result/` — 画像生成したリザルト用の木枠、終了見出し、数字0〜9、統計アイコン。動的な値は数字画像を組み合わせて表示します。
- `assets/title-logo.webp` — 透過背景のタイトルロゴ（元画像は `assets/title-logo.png`）。タイトル画面はロゴ・スタートボタン・ベストスコア（ランキング有効時はランキングボタンも）です。
- `main.js` — Three.js描画、Rapier物理、ゲーム進行、効果音、ランキング通信（`RANKING_API`）
- `server/` — レンタルサーバーに置くランキングAPI（PHP＋MySQL）。設置手順は [server/README.md](server/README.md)。GitHub Pages には `_config.yml` で公開対象から外しています

## 使用バージョン

- Three.js `0.186.1`
- `@dimforge/rapier3d-compat` `0.21.0`

効果音はWeb Audio APIでリアルタイム生成しているため、音声ファイルはありません。
